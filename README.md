# Demo Close Kit

Demo Close Kit is a Next.js app for creating personalized website demos and outreach copy for local business owners.

Use it to:

- Enter a prospect's business details.
- Preview a polished landing page tailored to that business.
- Copy a short email or text message to ask if the owner wants to see the demo.
- Load Riyadh lead presets and open prefilled WhatsApp Business chats.
- Reference simple starter pricing for closing paid website work.

## WhatsApp Business outreach

The app includes a safe click-to-chat workflow for WhatsApp Business:

1. Pick a Riyadh target from the WhatsApp Business outreach panel.
2. Review the generated bilingual message.
3. Copy the message or click **Open WhatsApp**.
4. WhatsApp opens a prefilled chat; you still review and press send yourself.

No private phone number or WhatsApp API credentials are stored in this app.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Next.js.

## Scripts

- `npm run dev` - start the development server.
- `npm run build` - create a production build.
- `npm run start` - run the production server after building.
- `npm run lint` - run ESLint.
